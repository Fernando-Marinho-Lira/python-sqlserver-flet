# Python + SQL Server + Flet

**Projeto prático de integração entre Python, Microsoft SQL Server e interface gráfica com Flet.**

## Apresentação

Este repositório foi criado para organizar e apresentar um projeto desenvolvido anteriormente, divulgado no LinkedIn como **Projeto Prático | SQL Server + Python + Flet**.

O objetivo desta etapa é preparar a documentação e a estrutura para receber os **arquivos originais**, que estão armazenados em outro computador (notebook).

> **Status do repositório:** documentação inicial publicada. O código-fonte e os scripts SQL originais **ainda não foram enviados**. As funcionalidades, dependências, arquitetura definitiva e instruções de execução serão descritas após análise dos arquivos reais.

## Tecnologias associadas ao projeto

- **Python** — linguagem de programação utilizada no projeto.
- **Microsoft SQL Server** — banco de dados associado à aplicação.
- **Flet** — tecnologia da interface da aplicação.

A documentação anterior também faz referência a **PyInstaller** no processo de empacotamento. Isso será confirmado nos arquivos originais antes da publicação de instruções de compilação ou distribuição.
